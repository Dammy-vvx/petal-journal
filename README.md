# Petal Journal 🌸

A personal, local-first period journal built as a Progressive Web App (PWA).

## Privacy

- Journal information is intended to remain in this browser/device using browser storage.
- There is no cloud account or sync service built into this static app.
- This repository is public, so the source code is visible to everyone.
- The local app login is a convenience lock, not a substitute for device security or data encryption. Anyone with access to the browser profile or its stored data may be able to access local data.

## Run locally

Serve this folder over localhost (for example, `py -m http.server 8000`) and open `http://localhost:8000`.

## Deploy

This repository includes a GitHub Actions workflow for GitHub Pages. In **Settings → Pages**, choose **GitHub Actions** as the build and deployment source if it is not selected already.
